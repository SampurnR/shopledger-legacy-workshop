# Issue tracker: GitHub

Issues and specs for this repo live in the GitHub repository
`SMKehTDOG2335/shopledger-legacy-workshop`. Use the `gh` CLI from this checkout.

Before creating an issue, verify the target with `gh repo view --json nameWithOwner`.
File issues only in this repository. Do not treat pull requests as triage requests.

When a skill asks to publish work, create a GitHub issue. When it asks to fetch a ticket, read it with `gh issue view <number>`.
