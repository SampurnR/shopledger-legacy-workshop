The shop ledger, in one small application.

ShopLedger helps a wholesale and retail counter record orders, calculate GST, follow stock, and manage customer credit.

Local application required. This page is project documentation. The working POS needs its Express server and local JSON data store.

What it does

Bill accuratelyHSN-based GST, coupons, and printable tax invoices.
See stockProduct availability, reservations, and reorder visibility.
Track creditKhata balances, customer limits, and settlements.

Run it locally

Install the locked dependencies, then start the Node.js application:

npm ci   npm start

Open http://localhost:3000. Run the test suite with node --test.

Architecture

The static interface calls Express routes; business rules live in lib/, while data/db.json retains operational records.

Source and local setup instructions are in the repository README.
