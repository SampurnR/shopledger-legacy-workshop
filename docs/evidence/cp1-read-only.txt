I AM SURE
ShopLedger is a CommonJS / Express billing, inventory and customer credit app.
The browser has POS, Order History, Customer Khata, and Inventory & GST Audit.

MODULE MAP
public/: HTML, CSS and browser JavaScript.
server.js: static UI, four /api routers, printable invoice endpoint.
routes/products.js: products and coupons.
routes/orders.js: order creation, history, lookup and cancellation.
routes/customers.js: customer accounts and settlements.
routes/reports.js: dashboards, reconciliation, pricing preview, export.
lib/inventory.js: sellable stock, deductions and releases.
lib/pricing.js: discounted per-line GST and checkout totals.
lib/coupons.js: normalization, eligibility, caps and active coupons.
lib/tax.js: HSN slabs, explicit rates, fallback and CGST/SGST split.
lib/orders.js: order records, filtering, sorting and cancellation.
lib/dates.js: date formatting and comparisons.
lib/ledger.js: balances, credit limits, charges and settlements.
lib/invoice.js: separately computed figures and printable HTML.
lib/reports.js: summaries and invoice versus ledger reconciliation.
lib/store.js: synchronous JSON persistence and audit log.
config.js: shop, tax, coupons, inventory, port and export key.
data/db.json: application state.

PLACING AN ORDER
UI POST /api/orders -> read DB -> resolve server-side product prices ->
check sellable stock -> validate coupon -> pricing.computeTotals ->
optional Khata credit check/debit -> deduct physical stock -> add order ->
append audit -> write JSON -> HTTP 201 -> UI refresh.
