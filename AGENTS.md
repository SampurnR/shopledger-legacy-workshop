# ShopLedger development guide

## Verified technology stack

- Node.js application using CommonJS JavaScript modules.
- Express (`^4.17.1`) and body-parser (`^1.19.0`) are the declared dependencies.
- The frontend uses HTML, CSS, browser JavaScript, and XMLHttpRequest JSON API calls.
- Persistence uses synchronous Node.js filesystem reads and writes to `data/db.json`.
- Printable invoices are HTML generated by the server.

## Module map

## Commands

Run these commands from the project root when the task authorizes them.

| Task | Command | Verified behavior |
| --- | --- | --- |
| Install dependencies | `npm install` | Installs dependencies declared in `package.json`. |
| Run application | `npm start` | Executes `node server.js`. Uses `PORT` when set, otherwise port 3000. |
| Execute test script | `npm test` | Currently prints `Error: no test specified` and exits with status 1. The test script is a placeholder. |

## Mandatory development rules

- Write characterization tests before changing existing behavior.
- Modify only the modules relevant to the selected ticket.
- Tests must use in-memory or isolated temporary data and must never modify `data/db.json`.
- Do not introduce new dependencies.
- Make the smallest safe fix and review changes before opening a pull request.
