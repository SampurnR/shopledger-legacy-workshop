# ShopLedger Agent Instructions

## Stack

- Node.js with CommonJS modules
- Express 4 server
- Vanilla HTML, CSS, and browser JavaScript
- JSON file persistence in `data/db.json`
- Built-in Node test runner via `node --test`

## Module map

- `server.js` wires Express, static assets, and API routes.
- `routes/` exposes product, order, customer, pricing, and report endpoints.
- `lib/store.js` reads and writes `data/db.json`.
- `lib/pricing.js`, `lib/coupons.js`, and `lib/tax.js` calculate order totals.
- `lib/inventory.js` manages sellable stock and reservations.
- `lib/orders.js` creates, lists, and cancels orders.
- `lib/ledger.js` manages Khata billing and settlements.
- `lib/invoice.js` renders printable invoices.
- `lib/reports.js` builds dashboard and GST reconciliation data.
- `public/` contains the browser UI.

## Commands

- `npm start` starts the local server on port 3000.
- `node --test` runs the test suite.

## Rules

- Write characterization tests before changing behavior.
- Change only the module(s) the ticket is about.
- Tests use in-memory data and never touch `data/db.json`.
- Add no new dependencies.
- Do not commit `package-lock.json` generated by workshop setup.
