# Ticket 2 bonus follow-up: exact-stock boundary

This follow-up records the exact-stock fix that came after the ticket-2 implementation described in [log 5](5.md). Log 5 accurately said that exact-stock behavior remained unchanged at that point; the later bonus fix was missing from the evidence pack.

`lib/inventory.js` now rejects an order only when its quantity exceeds sellable stock. An order equal to sellable stock is accepted, including when part of physical stock is reserved. `tests/ticket-2.test.js` covers both the equality boundary and an over-stock request using in-memory product data.

The focused regression tests were added with this follow-up. They have not been run in this session.
